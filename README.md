# pcsrt

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

Use Raspberry Pi OS Lite (64-bit) based on Debian 13 Trixie, released on 2025-12-04. [Download](https://downloads.raspberrypi.com/raspios_lite_arm64/images/raspios_lite_arm64-2025-12-04/2025-12-04-raspios-trixie-arm64-lite.img.xz).

This project was created using `bun init` in bun v1.3.5. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
